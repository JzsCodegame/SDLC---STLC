YOUR COMPUTER. YOUR PRACTICE.

Set up the local lab in three steps.

The Academy provides the kit; your Windows computer runs the editor, practice app, and optional test browser locally.

01 / CHECK

Prepare Windows

Use Windows 10 or 11 (x64) with Node 24.x and npm, Git 2.x, and Microsoft Edge or Google Chrome. An Internet connection is needed for the first install.

.\Lab.cmd check
02 / INSTALL

Make one practice copy

Extract the verified kit, then install. It creates Mini Quiz Student Work/<version>/practice-app beside the kit and does not overwrite a copy you already edited.

.\Lab.cmd install
03 / RUN

Choose your check

Start the Help Desk, run API or browser checks, and keep your manual records in the student-work folder.

.\Lab.cmd start
Commands and troubleshooting

Run each command from the extracted kit folder. A headed Playwright or open Cypress run uses a browser on your computer; it does not run PowerShell remotely or give the Academy control of your browser.
