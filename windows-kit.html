WINDOWS STUDENT GUIDE

From download to your first visible test.

Follow the steps below in order. Your Windows 10/11 x64 computer runs the practice app and browser. You need Internet access and at least 2 GiB of free disk space.

Get the Windows lab kit →

1. Extract the download

Open Downloads in File Explorer. Right-click the ZIP → Properties → Unblock (if shown) → Apply. Then right-click it → Extract All. Open the extracted Mini Quiz Lab folder. You should see Setup.cmd and Lab.cmd. Do not run files from inside the ZIP.

2. Double-click Setup.cmd

Keep its window open until you see SETUP SUCCEEDED. It checks Node 24 with npm, Git, Edge/Chrome and VS Code. Compatible tools print PASS and are kept. Missing or unsupported tools are installed or updated. Windows may ask you to approve an installer.

Setup then installs the pinned Playwright, Cypress and app dependencies, verifies Cypress, builds the Help Desk and prints your editable folder. Running setup again preserves your saved work.

If you see SETUP STOPPED, read the first error above it, fix that issue and retry. If App Installer is missing, install/update App Installer from Microsoft Store. School policy may require your administrator; do not disable security settings.

3. Open PowerShell in the kit folder

In File Explorer, open the folder containing Lab.cmd. Click its address bar, type powershell and press Enter. Type each command below and press Enter:

Get-Location
Get-ChildItem Lab.cmd

The first shows your folder. The second must show Lab.cmd. If it cannot find that file, return to the folder containing Lab.cmd and repeat this step.

To move to a folder manually, replace this example with your own extracted folder path. Keep the quotation marks:

Set-Location "C:\Users\YourName\Downloads\Mini Quiz Lab 1.1.0"

4. Run your first visible Playwright test

.\Lab.cmd test playwright-headed

This builds your saved app, starts its own test server, opens a browser and runs the example checks. You do not need to start the app separately. Browser actions are slowed so you can watch. The browser closes when tests finish, and the terminal shows passed/failed counts.

To view the test report:

.\Lab.cmd report

5. Find and edit your test

.\Lab.cmd folder

This opens your editable practice folder and prints its exact path. In VS Code, choose File → Open Folder and select that folder. Open tests/playwright/help-desk.spec.ts, make your change and save it. Return to the kit PowerShell window and run the same test command again:

.\Lab.cmd test playwright-headed

Edit the student working copy; keep the downloaded template unchanged.

6. Explore the app manually

.\Lab.cmd start

The Help Desk opens at http://127.0.0.1:4173/. Keep this terminal open while using it. Press Ctrl+C in the terminal to stop it. Use fictional records. Tests use separate data.

Other checks, when your instructor asks

Run API tests with .\Lab.cmd test api. Open Cypress with .\Lab.cmd test cypress-open, select E2E Testing, choose Edge/Chrome, then open help-desk.cy.ts. Check downloaded files with .\Lab.cmd verify.

Your source, tests and notes live in Mini Quiz Student Work beside the extracted kit. A new version creates a separate folder and preserves the old version. See the included README for troubleshooting, ports and backing up your work.
