Prepare the local practice pages for a workshop

Online paired examples already target the hosted practice pages. For a workshop using localhost, download this separate fixture bundle. It adds exercise pages; it does not replace or reinstall Windows kit 1.1.3.

Download UI practice fixtures ↓ · View file checksums

  1. Extract into a new folder. Open the included README.txt.
  2. Open your editable practice-app project. Copy the supplied public files into its public folder. Preserve other files; back up any same-named file before replacing it.
  3. From practice-app, run npm run build, then npm start in a separate terminal. Open http://127.0.0.1:4173/ui-advanced.html.
  4. Follow the workshop prerequisites and commands. Stop your owned server with Ctrl+C.

Use a separate local project for advanced configuration workshops. They do not automatically change the instructor-hosted workspace. Mock order endpoints need the supplied test intercepts; they are not real backend services.

What does coverage mean here?

This is a dated inventory of documented capabilities, not a claim that every API method, overload, browser, plugin or service has been tested. Paired examples are compact runnable test scenarios. Workshops may require additional project files or environments and show their own verification state. Boundaries explain unsupported, version-dependent or separately licensed features. Open gaps remain visible rather than counted as finished.

Use demo data. Paired examples run in your assigned workspace or current Windows kit. Workshops have separate prerequisites: use a separate local practice project unless their instructions explicitly support the hosted workspace. Keep your existing configuration and saved work. Examples are checked against the pinned toolchain; official documentation can describe newer versions. No paid cloud account is needed for the paired UI exercises.
